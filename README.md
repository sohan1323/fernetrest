## 🌟 Key Features

* **Authenticated Encryption**: Uses `Fernet` (AES-128 in CBC mode + HMAC-SHA256 for integrity verification).
* **Strong Key Derivation**: Employs PBKDF2 with **600,000 hashing rounds** (meeting current OWASP recommendations) to defend against GPU-accelerated brute-force attacks.
* **Salt-Injected Payloads**: Generates a 16-byte cryptographically secure random salt (`os.urandom`) per file, defeating precomputed Rainbow Table attacks.
* **Universal File Support**: Operates strictly on raw binary streams (`rb`/`wb`), allowing seamless encryption of text files, PDFs, videos, images, databases, and ZIP archives.
* **Zero Shoulder-Surfing**: CLI uses `getpass` to prevent passwords from echoing on the terminal screen.
* **Tamper-Evident**: If even a single bit of the encrypted file is altered or modified, decryption aborts immediately with an authentication error.

## 🛡️ Security Architecture

### Cryptographic Pipeline

```text
================================== ENCRYPTION ==================================
User Password ──┐
                ├──> [ PBKDF2-HMAC-SHA256 (600,000 Rounds) ] ──> Fernet Key (32 Bytes)
16-byte Salt  ──┘                                                          │
(os.urandom)                                                               │
                                                                           ▼
Plaintext File (Binary) ──────────────────────────────────────────> [ Fernet Encrypt ]
                                                                           │
                                                                           ▼
Encrypted Output (.enc): [ 16-Byte Salt ] + [ AES-128-CBC + HMAC-SHA256 Ciphertext ]

================================== DECRYPTION ==================================
Encrypted File (.enc) ──┬──> First 16 Bytes (Salt) ──┐
                        │                            ├──> [ PBKDF2 (600,000) ] ──> Re-derived Key
User Password ──────────┼────────────────────────────┘                                    │
                        │                                                                 │
                        └──> Remaining Bytes (Ciphertext + HMAC) ─────────────────────────┼──> [ Fernet Decrypt ]
                                                                                          │            │
                                                                                          │   (Integrity Verified?)
                                                                                          ▼            │
                                                                                   Plaintext File ◄────┘
```

### Encrypted File Binary Layout
Output files (`.enc`) store the non-secret 16-byte salt directly at the head of the file:

```text
┌───────────────────────────┬────────────────────────────────────────────────────────┐
│  Salt (First 16 Bytes)    │      Authenticated Ciphertext (Remaining Bytes)       │
│  Generated by os.urandom  │      AES-128-CBC payload + HMAC-SHA256 Signature       │
└───────────────────────────┴────────────────────────────────────────────────────────┘
```

## 💻 CLI Usage

Once installed, the `fernetrest` command is available everywhere in your terminal.

### 1. Interactive Menu
Simply run without arguments:
```bash
fernetrest
```
```text
=======================================================
       fernetrest - Secure File Encryptor / Decryptor
=======================================================
1. Encrypt a file
2. Decrypt a file
3. Exit

Select an option (1-3): 1
Enter path to the file: confidential.pdf
Enter encryption password: 
Confirm encryption password: 

[*] Encrypting file (PBKDF2 with 600,000 iterations)...
[+] File encrypted successfully: confidential.pdf.enc
```

### 2. Direct Subcommands

```bash
# Encrypt a file (prompts securely for password without screen echo)
fernetrest encrypt secret.docx

# Encrypt and specify a custom output path
fernetrest encrypt secret.docx -o /backups/secret_backup.enc

# Decrypt a file
fernetrest decrypt secret.docx.enc

# Decrypt and specify custom restored filename
fernetrest decrypt secret.docx.enc -o restored_secret.docx
```

## 🐍 Python API

You can also use `fernetrest` as a library inside your Python applications:

```python
from fernetrest import encrypt_file, decrypt_file

password = "SuperSecretMasterPassword!2026"

# 1. Encrypt any document or media file
encrypted_path = encrypt_file("database.sqlite", password=password)
print(f"Encrypted file created: {encrypted_path}")

# 2. Decrypt the file
restored_path = decrypt_file("database.sqlite.enc", password=password)
print(f"File restored to: {restored_path}")
```

### Advanced Usage (Custom Iterations & Key Derivation)

```python
import os
from fernetrest import derive_key, SALT_SIZE

# Generate a salt and derive a raw 32-byte Fernet key manually
salt = os.urandom(SALT_SIZE)
fernet_key = derive_key(password="Passphrase", salt=salt, iterations=600000)
```

## 🔒 Threat Model & Defenses

| Threat | Attack Vector | `fernetrest` Defense |
|---|---|---|
| **Data Theft at Rest** | Stolen laptop / compromised disk / leaked backup | High-strength AES-128 encryption renders files unreadable without the password. |
| **Rainbow Table Attacks** | Precomputed password-to-hash tables | Each file receives a unique 16-byte random salt (`os.urandom(16)`), invalidating precomputed lookup tables. |
| **GPU Brute-Force** | Password guessing with hashcat / GPUs | PBKDF2 stretching with **600,000 rounds of HMAC-SHA256** drastically increases per-guess compute cost. |
| **Ciphertext Tampering** | Bit-flipping / malicious payload injection | Built-in **HMAC-SHA256** authenticity verification fails immediately (`InvalidToken`) if even 1 bit is altered. |
| **Shoulder Surfing** | Snooping passwords over the shoulder | Terminal password inputs use Python's `getpass` module, never echoing keystrokes to stdout. |
